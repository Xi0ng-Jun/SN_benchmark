## Contracts and decisions

- Deadline is the optimisation wall-time budget, endpoint excluded. Pending jobs are not submitted after expiry. Started adapter work cooperatively stops and retains request identity so evidence is never fabricated.
- Round timebox limits starting cards. Carry-over must keep the original parent/split and only be adopted after rebasing and measuring against a changed parent; no stale candidate can advance the pointer.
- Review is skipped below the minimum possible adoption threshold or after safeguard veto; it still runs for qualified candidates because gaming can veto them.
- Speculative analysis is reusable only for the same parent and exact target round, and contains in-progress labels; otherwise discard it. Diagnostic caches are keyed by version/sample/k.
- Preparation-path hints report uncertainty at symbol boundaries; touching an answer prompt does not imply a cold preparation.
