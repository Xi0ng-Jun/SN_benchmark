## 1. Summary of Accepted Findings & Spec/Implementation Fixes

### (a) Deferred Server Parameters, Env Isolation & Secret Hygiene

| # | Fable 5.2 Finding | Verification & Accepted Resolution |
|---|---|---|
| A1 | **`config.server.json` lacked an explicit schema** for deferred server parameters (`SSAP_MODEL`, `SSAP_GATEWAY`, `SSAP_UPSTREAM_KEY` / `SSAP_UPSTREAM_KEYS`, `upstream_auth_header`/`prefix`, `proxy_port`, `parallel`, `T_warn`, `T_soft`, `Delta_T_rep`, `Delta_S_rep`, `min_remaining_for_repair_sec`, `tail_buffer_sec`, `kill_grace_sec`, `theta_gw_max`, `agent_image`). | **ACCEPTED.** Full explicit schema added in `configs/alw/config.server.json` with env interpolation (`${VAR:-default}`), CLI overrides on `ssap alw-*`, and resolved non-secret metadata recorded in `artifact_summary.json`. |
| A2 | **Claude Code Sub-Model Homogeneity had 7 slots, missing `CLAUDE_CODE_SUBAGENT_MODEL`** (`harbor/agents/installed/claude_code.py:1880`), and prefix clear missed `AWS_*`, `MAX_THINKING_TOKENS`, `DISABLE_PROMPT_CACHING`. | **ACCEPTED.** Expanded homogeneity pinning to **8 slots** (adding `CLAUDE_CODE_SUBAGENT_MODEL`) and switched host Harbor launch to a strict allowlisted environment stripping `ANTHROPIC_*`, `CLAUDE_*`, `AWS_*`, `MAX_THINKING_TOKENS`, `DISABLE_PROMPT_CACHING`, and all `*_PROXY`/`*_proxy` vars. |
| A3 | **Option B (passing credentialed `http_proxy` into Harbor env) leaks credentials** because `harbor/utils/env.py` only redacts keys matching `KEY\|SECRET\|TOKEN\|PASSWORD\|CREDENTIAL\|AUTH`, writing `http_proxy=http://user:pass@...` verbatim to `config.json`; Harbor also installs Claude via `downloads.claude.ai/claude-code-releases/bootstrap.sh` on Debian/Ubuntu rather than npm unless Alpine. | **ACCEPTED.** Option B (`http_proxy` in Harbor job/agent env) is **prohibited**; `harbor_runner.py` rejects credentialed proxy vars in job configs, enforces Option A (`agent_image` override via generated compose overlay `services.main.build.args.ALW_BASE_IMAGE` while leaving verifier image untouched) + `kwargs.version="2.1.302"`, and probes `downloads.claude.ai` in `preflight_alw.sh`. |
| A4 | **Proxy auth header & credential scrubbing edge cases**: Harbor sets `ANTHROPIC_API_KEY` (`x-api-key`) in-container whereas standalone `claude -p` may send `Authorization: Bearer`; narrow regex `(https?://)[^/@\s]+@` missed `/` in passwords, multiple `@`, `socks5://`, and literal secret values. | **ACCEPTED.** Zero-cache metering proxy is **mandatory** for model runs, accepts **either** `x-api-key` or `Authorization: Bearer` matching the per-trial ephemeral token, forwards upstream via configurable `upstream_auth_header`/`upstream_auth_prefix`, and scrubs both `[a-zA-Z][a-zA-Z0-9+.-]*://[^\s@]+@` URLs and literal secret values from all persisted configs/summaries/logs. |

## 2. Explicitly Rejected Suggestions (Preserving `AGENTS.md` & `mcr-formal.tex` v2 Invariants)

| # | Suggestion Considered in Review | Disposition & Principle Enforced |
|---|---|---|
| R1 | Implementing container entry via a custom Harbor Python subclass (`AgentConfig.import_path` importing `harbor.agents.installed.claude_code`). | **REJECTED.** `AGENTS.md` strictly prohibits importing third-party checkouts (`eda`, `analoglayoutworld`, `harbor`) anywhere in `ssap` or `tests/`. We integrate with Harbor 100% via declarative JSON config (`kwargs.config`, `kwargs.version`, top-level `extra_instructions: list[str]`, top-level `n_concurrent_trials`), Docker Compose overlays (`extra_docker_compose`, `volumes`), and the container-side `claude` wrapper `mcr_entrypoint.py`. |
| R2 | Dropping mid-trajectory write-through promotion in favor of finalizing `submission/` only once at Phase A exit (`fable:70`). | **REJECTED.** `AGENTS.md` Invariant 1 and `docs/mcr-formal.tex` Invariant 1 (`inv:fallback`) require continuous atomic write-through to `submission/` so that an unexpected hard timeout (`T_max`) or container termination still leaves the highest mirror-certified checkpoint on the canonical submission path. Fixing Tier-0 weak dominance + Rule 2(b) `>=` gate-margin saturation + `additionalContext` notification eliminates false reverts while preserving Invariant 1. |
| R3 | Embedding a public-testbench `ngspice` post-simulation scorer `y_hat_mir` directly inside fixed `H_base` (`fable:65`). | **REJECTED for `H_base` (kept as Phase 2/3 candidate).** `H_base` must remain fast, deterministic, and zero-parameter (`m_1..m_6`); Rule 2(b) `>=` with binary gate-margin saturation (`u_j = 0.0` once `m_j = 1`) already allows post-sim fixes to promote freely in `H_base` without running slow `ngspice` sweeps on every promote. Promoting `m_pex` / `m_postsim` remains a Stage 0 concordance-verified Phase 2/3 candidate (`scope="terminal_only"` for Path 1 or `scope="trajectory"` for Path 2). |
| R4 | Questioning/removing the pre-registered `gateway_wait_seconds / wall_seconds > theta_gw_max` `infra_error` separation rule (`fable:112`). | **REJECTED (rule retained, metric sharpened).** Separating gateway outages/queueing stalls from agent task failures with paired reruns and `delta_worst` lower-bound reporting is a core hygiene requirement of `AGENTS.md` and `docs/mcr-formal.tex` §2. Measuring `gateway_wait_seconds` strictly as upstream TTFB + `429/5xx` backoff wait eliminates correlation with normal generation length while preserving `infra_error` protection. |
| R5 | Any legacy v1 / `method-v5` statistical veto gates (`W_i`, `0.49/\|B\|`, McNemar, `n_10 <= 1`, `p <= 0.05`, `P-SHA`) or request-level proxy replay. | **CONFIRMED ZERO.** Verified absent across all specs; strictly excluded from implementation. |
