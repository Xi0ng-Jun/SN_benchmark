原型是离线 HTML/CSS/JS，直接打开 `prototype/index.html`。全部为构造数据，操作只改变本页内存；没有服务器保存、Agent 推理或正式评测。它用于讨论，不是生产界面的逐像素规格；生产技术和视觉细节按实际接入调整。未进行浏览器渲染、点击流或可用性验收。

推荐预览：进入任务 → 提议计划 → 调整选题 → 演示提交 → 推进阶段 → 打开成绩／证据并保存判断 → 查看改动与验证 → 比较结论 → 回看历史。任意自选题单只演示提交，构造全流程使用独立的固定 12 题计划。

## 当前明确的方向与可调整的方案

明确方向：单服务器可访问 SN；workspace／worktree 组织工作；手动操作与 Agent 协作；评测、调查、修改、验证和历史连贯可用；界面与技术尽量借鉴 Paseo。评测结果、人工判断与模型假设保留各自来源。

方案仍可调整：独立应用或插件接入、三栏的具体布局、任务与会话如何呈现、工作卡数量、组件拆分、技术版本、源码捕获及开发顺序。无需在设计阶段全部定案，也无需把所有材料当作开工审批清单。

开发时优先接通一个可使用的工作面；SDK、源码运行绑定和长任务生命周期的问题在对应边界解决。原型的密度、阅读顺序和真实规模体验随使用反馈收敛。当前 clean runner 的限制是实现缺口，不是永久产品限制。

Paseo 目录内旧原型与 ZIP 保留为历史预览。本目录是可纳入版本管理的当前设计来源，不依赖外部 Git 忽略目录。2026-10-11 设计修订最初仅改文档，随后本地开发切片的实现与验证另见使用说明；没有新模型评测或生产部署。
